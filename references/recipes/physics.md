# 物理引擎 Matter.js（M8 的展开）

先读 `references/recipes/motion.md` 的 M8 物理碰撞。本文件是 M8 的 7 个具体模式（M8-1 – M8-7）、参数表和实现注意。

Matter.js 把界面元素变成有物理属性的物体：会掉落、碰撞、弹开、堆叠、被拖动。**只用在特定的微交互时刻，不是整个页面都用物理。**

## 先问：不用物理引擎能不能做？

能就不用。物理引擎更重、结果随机、键盘难操作。

| 想要的效果 | 先用 | 只有这种情况才上 Matter.js |
|---|---|---|
| 拖拽排序时周围让位 | F2 拖拽让位（spring 连续让位，更轻，支持键盘） | 元素要自由碰撞，不是一条整齐的列表 |
| 删除时飞向垃圾桶 | F8 卡片删除飞走 | 多个元素飞的时候要互相撞 |
| 收藏时飞进图标 | F8 的飞行 + 目标图标 `spring-pop` | — |
| 气泡按大小推挤 | D10 气泡图（d3-force / pack） | 需要重力和回弹 |
| 被吸到目标上 | M1 磁吸 | 很多元素同时被吸 |

## 7 个模式

### M8-1 掉落堆叠

- **适合**：新内容入场、抽奖翻牌、卡片收集。
- **提示词**：用 Matter.js 实现卡片从顶部掉落的效果，卡片之间有碰撞和反弹，最终自然堆叠在底部。每张卡片弹性（restitution）0.6，摩擦力 0.1。
- **注意**：入场掉落每个会话最多播一次，只用在「第一次出现内容」这类时刻。dashboard 指标卡不要每次打开都掉。

### M8-2 弹簧让位

- **适合**：拖拽排序、插入新项、选中高亮。
- **提示词**：用 Matter.js 实现拖拽排序时的弹簧让位效果，拖入的元素靠近时，周围的元素用弹簧约束被推开，松手后弹回新位置。
- **注意**：整齐的列表先用 F2，不用物理引擎。

### M8-3 爆炸散开

- **适合**：清空列表、删除标签、清空购物车。
- **提示词**：用 Matter.js 实现点击删除时元素爆炸散开的效果，每个元素从中心向外飞出，带旋转和随机速度，碰到边界反弹后逐渐停下。
- **注意**：散开后要真的从 DOM 移除，并提供撤销。这是惊喜类动效，只放在低频操作上。

### M8-4 重力吸引

- **适合**：收藏归集、归拢动画、分组归类。
- **提示词**：用 Matter.js 实现所有元素被吸引到中心点的效果，越靠近中心速度越快，到达后轻微回弹再停稳。
- **注意**：只有一个元素被吸时，用 M1 磁吸就够了。

### M8-5 物理拖拽

- **适合**：可拖动的卡片、小游戏、文件整理。
- **提示词**：用 Matter.js 实现可拖拽的物理卡片，手指按住时停住，甩出去时有惯性和摩擦力，碰到边界反弹。
- **注意**：「按住就停」遵守 G5 飞行中可抓住。能拖的东西也要能用按钮或键盘完成同样的操作。

### M8-6 多米诺骨牌

- **适合**：批量操作确认、进度庆祝、「全部完成」。
- **提示词**：用 Matter.js 实现多米诺骨牌效果，点击第一个元素后，依次触发周围元素的倒下，形成连锁反应。
- **注意**：只放在罕见时刻（例如第一次全部完成）。日常的批量完成用 F3 批量勾选接力。

### M8-7 浮动悬浮

- **适合**：标签云、技能气泡、兴趣关键词展示。
- **提示词**：用 Matter.js 实现标签云浮动效果，每个标签在容器内缓慢漂浮，互相轻轻碰撞，带很小的空气阻力模拟失重感。
- **注意**：一直在动 = 背景氛围层。「克制」人格的项目不做；reduced-motion 时必须静止；页面隐藏时暂停。

## 物理参数

| 参数 | 含义 | 典型值 |
|---|---|---|
| `restitution` | 弹性 / 反弹 | 0.3 软弹，0.6 有弹性，0.9 很弹 |
| `friction` | 表面摩擦 | 0.05 很滑，0.5 粗糙 |
| `frictionAir` | 空气阻力 | 0.01 飘，0.1 沉 |
| `density` | 密度 / 重量 | 0.001 轻，0.01 重 |
| `stiffness` | 弹簧（Constraint）刚性 | 0.05 软弹簧，0.9 硬连接 |

**按项目人格选**（选定的值写进项目 MOTION-SPEC 的常量表，全项目统一）：

| 人格 | 感觉 | 参数 |
|---|---|---|
| 克制 | 厚重 | 一般不用物理；要用就 `restitution` ≤ 0.3、`frictionAir` 0.1、`density` 0.01 |
| 有表现力 | 高级 | `restitution` 0.3–0.5，`frictionAir` 0.02–0.05 |
| 有弹性 | 活泼 | `restitution` 0.6–0.8，弹跳明显 |

## 实现注意

- **引擎只算位置，DOM 负责画。** 每帧把物体的位置和角度同步到元素的 `transform`。`Matter.Render` 是调试用的画布，不用来画正式界面。
- **卡片不想翻滚**：给物体设 `inertia: Infinity`，它就不会转。
- **省电**：开 `enableSleeping`；所有物体静止后停掉 Runner；页面隐藏（`visibilitychange`）或滚出屏幕时暂停。
- **容器尺寸变化**：重建四周的边界墙，否则物体会掉出去。
- **拖拽的坑**：`MouseConstraint` 会拦截滚轮和触摸滚动，让页面滚不动。要移除它加在元素上的滚轮监听（`mouse.mousewheel`），触屏上用 `touch-action` 控制。
- **数量**：超过 50 个物体慎用；手机和 RN 上要更少，并真机测。RN 上物理在 JS 线程跑，位置要喂给 Reanimated，物体多了会掉帧，具体交给 `animate-expo` 判断。
- **无障碍**：DOM 顺序保持逻辑顺序，不随物理位置变；reduced-motion 时直接显示最终布局。

## 提示词模板

用 Matter.js 给这个组件加入物理效果，让 [元素] 在 [时机] 时 [物理行为]，弹性调为 [0.X]，摩擦力 [0.X]，目标是营造 [高级/活泼/有趣] 的感觉。

例如：用 Matter.js 给这个卡片列表加入物理效果，让每张卡片在页面加载时从顶部随机掉落，互相碰撞后自然堆叠，弹性 0.5，摩擦力 0.1，目标是营造活泼有趣的感觉。

## 可以用在哪

每一条都要先过 `animate` 的频率关和项目人格。

- **页面 / 组件**
  - dashboard 指标卡入场掉落：只在第一次出现数据时播一次（M8-1）。
  - 删除卡片飞向垃圾桶：先用 F8。
  - 选中某项时其他的被弹开、Tab 切换时老内容被挤出去、上传文件一个个弹进列表：用 M8-2 / M8-3 的思路。
  - Toast 从顶部掉下来、Modal 弹出时轻微弹跳再定住：只在「有弹性」人格的项目里用。`animate` 的规则是大多数 UI 不回弹，「克制」项目不做。
- **数据可视化**：气泡图用真实碰撞表现大小关系（同 D10）；饼图被切割时扇形掉落；堆叠柱状图逐根倒下；树状图从根节点长出来。这些只当解释性动画（第一次看、onboarding），不用在每天要读数的图表上。
- **惊喜时刻**：点赞时粒子散开、收藏时飞进收藏图标、抽奖翻牌、进度条满了之后庆祝。只放在低频时刻。

## 不要用

- 表单、表格等需要精确对齐的严肃数据场景。
- 内容很密集、信息量很大的 dashboard（物理效果会干扰阅读）。
- 移动端性能受限的场景，超过 50 个物理对象要慎重。
- 可访问性要求高的场景（物理的随机性不可预测）。
