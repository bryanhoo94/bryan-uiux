### P1 捏合换密度

- **用在**：相册、作品集、商品网格这类同一批内容需要不同密度浏览的页面。
- **提示词**：给网格加双指捏合的语义，缩放，按缩放比在大图、三列、文字行三档之间切换，每一项连续移动到新位置
- **参数**：捏合过程中网格 1:1 跟手缩放；松手按当前缩放比吸到最近一档（< 0.75 切到更密，> 1.33 切到更疏，起始值）；每一项用 FLIP / layout 动画从旧位置移到新位置，`spring-ui`。Web 触控板捏合是 `wheel` 事件且 `ctrlKey === true`。
- **打断**：换档动画中再次捏合，从当前位置继续跟手。
- **降级**：三档之间直接交叉淡入（opacity 200ms `--ease-out`）。
- **别用在**：只有一种合理密度的列表。桌面端没有触控板时，另给按钮切换档位。

### P2 滚动驱动动画

- **用在**：落地页叙事段、产品介绍、onboarding 讲解。
- **提示词**：把这段动画的进度绑定滚动位置，滚动可逆，停住时动画停在对应的进度上
- **参数**：没有时长和曲线，进度 = 滚动位置线性映射到 0–1。Web 优先用 CSS `animation-timeline: view()` / `scroll()`，不支持时退回 Motion `useScroll`。
- **打断**：天然可逆，不用处理。
- **降级**：直接显示最终状态，不绑定滚动。
- **别用在**：产品内每天高频使用的页面；用户要读或要操作的数据。

### P3 速度拖影

- **用在**：图片为主的长列表或横向画廊，快速滚动时增加速度感。
- **提示词**：列表滚动时按速度给内容加方向性模糊，速度归零时平滑恢复清晰
- **参数**：模糊量跟滚动速度成正比，上限 8px（起始值）。CSS `blur()` 没有方向，方向感用 SVG `feGaussianBlur stdDeviation="0 N"`（只在滚动方向模糊）。在滚动容器上整体加一次滤镜，不要每项加；每帧用 `requestAnimationFrame` 采样速度。速度归零时模糊量用 `spring-ui` 回到 0。
- **打断**：速度实时更新，不用处理。
- **降级**：完全不加模糊。
- **别用在**：文字为主的列表（模糊后读不了）；低端 Android 设备。

### P4 视差头图

- **用在**：个人主页、文章详情、商品或地点详情这类顶部有大图的页面。上滑时头图走得比内容慢，下拉时头图放大。
- **提示词**：顶部大图随页面上滑时只走内容一半的速度；滚动到顶，继续下拉时，大图按下拉距离放大，覆盖文字同步淡出，松手带阻尼回弹
- **参数**：
  - 上滑：进度绑滚动位置（同 P2），头图 `translateY(滚动距离 × 0.5)`。0.5 是起始值，这个数越接近 1，头图和内容的速度差越小，视差越弱。Web 优先 `animation-timeline: scroll()` 加 `animation-range: 0 图高`，只动到头图离开屏幕；头图外层 `overflow: clip`，下面的内容层要有不透明底色。
  - 下拉：下拉距离先过 `rubberband`；头图 `scale = 1 + 有效距离 / 图高`，`transform-origin: top center`；图上文字 `opacity = 1 − 有效距离 / 80px`（起始值）；松手 `spring-ui` 回到原位。
- **打断**：回弹中再按住，从当前位置继续跟手。上滑天然跟手。
- **降级**：reduced-motion 时上滑视差完全关闭，头图跟内容同速（同 M3）；下拉不放大，只保留 G7 的到顶阻尼。
- **别用在**：没有头图的页面，用 G7。同一页要 G9 下拉刷新时，下拉放大让给 G9，只留上滑视差。
- **桌面 / 手机**：手机两段都做。桌面只做上滑视差，头图别占满首屏，正文的开头要露出来。RN：`useAnimatedScrollHandler` 读 `contentOffset.y`，`interpolate` 算位移和缩放；Android 的滚动偏移默认不会变成负数，下拉放大不触发，不用硬做。

### P5 参考线吸附

- **用在**：画布、编辑器、排版工具里拖拽元素。
- **提示词**：拖拽时检测与参考线的距离，进入阈值，自动吸附并显示对齐线，吸附瞬间给一次轻微的位移顿挫
- **参数**：进入吸附 6px、离开吸附 10px（起始值，按屏幕像素算，不随画布缩放变）。进入阈值时直接跳到对齐位置，不插值，这一跳就是顿挫。对齐线 opacity 0→1 用 100ms `--ease-out`。移动端吸附瞬间加一次轻触觉反馈。
- **打断**：元素始终跟手，吸附只修正显示位置。
- **降级**：保留吸附和对齐线，这是功能不是装饰。
- **别用在**：自由手绘、需要像素级自由摆放的场景。按住 Alt / ⌘ 时临时关闭吸附。

### P6 弧线换列

- **用在**：网格列数变化时，例如窗口变宽、切换视图、P1 换档。
- **提示词**：网格列数变化时，每一项沿弧线移动到新位置，相邻项错开延迟
- **参数**：每项 FLIP 位移；x 用 `--ease-in-out`、y 用 `--ease-out`，两条曲线不同就会走出弧线；250ms；每项错峰 30ms，项多时按行错峰。
- **打断**：动画中列数再变，从当前位置重新算目标（用 transition 或 spring，不用 keyframes）。
- **降级**：新布局直接交叉淡入。
- **别用在**：拖动窗口大小的过程中。等 resize 停下再播。

### P7 悬浮元素自动反色

- **用在**：浮在内容上的导航栏、悬浮按钮、固定 logo，页面背景深浅交替。
- **提示词**：悬浮元素按背后区域的亮度自动反色，滚动时连续过渡，不做硬切
- **参数**：简单版用 `mix-blend-mode: difference`，只适合纯黑或纯白元素。精确版给每个区块标 `data-theme="dark|light"`，用 IntersectionObserver 判断悬浮元素下方是哪个区块；两个区块交界落在悬浮元素范围内时，按交界位置比例插值颜色。两种颜色状态都要过 WCAG 4.5:1。
- **打断**：颜色随滚动连续变，不用处理。
- **降级**：颜色变化保留，它不是位移。
- **别用在**：背景是亮度不均的照片。改用半透明底板加 `backdrop-filter`。

### P8 选中项聚焦

- **用在**：横向卡片轮播、套餐或方案选择、同层级几选一。
- **提示词**：选中纵向放大提亮，同层未选中降低饱和度，并轻微缩小和模糊
- **参数**：选中卡片变高（用 layout / FLIP 动画，不要 `scaleY` 拉伸文字），`brightness(1.05)`；未选中 `scale(0.95)`、`saturate(0.6)`、`blur(2px)`（起始值）；200ms `--ease-out`。
- **打断**：transition 随时改目标。
- **降级**：保留饱和度和亮度变化，去掉缩放和模糊。
- **别用在**：未选中项还需要被阅读比较的地方，例如价格表。这种情况只降饱和度，不模糊。

### P9 吸顶分类标签

- **用在**：一页分好几段、要滚很久才看完的页面：商品分类、FAQ、文档、长设置页。标签回答「我现在在哪一段，还有哪几段」。
- **提示词**：分类标签栏滚到顶部后吸住不动，指示条跟着当前所在的分类走；点标签平滑滚到对应分类，滚动过程中指示条直接停在目标上，不扫过中间的标签
- **参数**：
  - 吸顶：`position: sticky`。页面已有顶栏时 `top: var(--nav-h)`，层级低于顶栏；一页只能有一个元素贴 `top: 0`（`references/visual/new-page/references/mobile-floor.md` 的 M5）。祖先用 `overflow: clip`，不要 `hidden`，不然吸不住。
  - 跳转位置：`html { scroll-padding-top: 顶栏高 + 标签栏高; }`，标题就不会被盖住，键盘和锚点跳转也一起对了。
  - 当前段：一个 IntersectionObserver 看全部分段，`rootMargin` 收成标签栏下面的一条线（上边距 = 顶栏高 + 标签栏高，下边距 = 视口高 − 这个数 − 1px），压在线上的那段就是当前段。最后一段加 `min-height: calc(100dvh - 顶栏高 - 标签栏高)`，不然滚到底也碰不到线，最后一个标签亮不了。
  - 指示条：一根 1px 宽的条，`translateX(标签左边) scaleX(标签宽)`，`transform-origin: left`，200ms `--ease-out`。选中项再加粗一档，不能只靠颜色。
  - 点标签：点下去马上高亮目标并上锁，滚动期间不理 observer。不上锁的话，指示条会把中间每一格都扫一遍。每次 `scroll` 事件把松锁计时重置成 150ms（起始值），停下来才松锁；松锁时用 `getBoundingClientRect` 按那条线重算一次当前段，observer 这时的结果可能还没到。不用固定时长松锁（长距离平滑滚动超过 1 秒），也不只靠 `scrollend`（Baseline 2025，旧设备没有）。
  - 标签放不下：标签栏 `overflow-x: auto`，当前标签自动滚到中间。用 `标签栏.scrollTo({ left })`，不要用 `标签.scrollIntoView()`，它会把页面自己的平滑滚动打断，页面停在半路。
- **打断**：滚动中再点别的标签，直接换目标。滚轮、手指、键盘一动就松锁，交还给滚动。
- **降级**：reduced-motion 时点标签直接跳（`behavior: 'auto'`），指示条不过渡。「克制」人格同样不过渡。没有脚本时标签是普通锚点，照样能跳。
- **别用在**：不到 3 段（起始值）或者一屏能看完的页面；点了整块内容换掉的切换（那是 Tab，见 `references/visual/navigation.md`）。
- **桌面 / 手机**：手机顶部横滑一排；标签栏是最顶上一层时 `top: 0` 加 `padding-top: env(safe-area-inset-top)`。平板放得下就不横滑。桌面的商品分类用顶部标签；文档、设置这类段多的页面改成左边吸住的竖排目录，sticky 的条件见 `references/visual/dashboard-layouts.md` 的 K3。RN：短页面 `ScrollView` 加 `stickyHeaderIndices`；长列表用 `SectionList`，`onViewableItemsChanged` 定当前段，`scrollToLocation({ sectionIndex, itemIndex: 0, viewOffset: 标签栏高 })` 跳转，跳到没渲染的段要有 `getItemLayout` 或 `onScrollToIndexFailed`。上锁的道理一样，松锁放在滚动结束事件里，加计时兜底。
- **无障碍**：这是页内导航，不是 Tab。`<nav aria-label="本页分类">` 里放 `<a href="#id">`，当前项 `aria-current="true"`，不写 `role="tablist"`。点击后焦点移到分段标题（`tabindex="-1"`，`focus({ preventScroll: true })`）。点击区 ≥ 44px。

### P10 封面收进导航栏

- **用在**：个人主页、商品或文章详情这类顶部有大封面的页面。往下看内容时，顶栏还告诉人「这是谁的页面」。
- **提示词**：页面上滑时，大封面收成顶部导航栏：头像缩小移到导航栏左边，标题淡入，导航栏背景淡入毛玻璃；往回滚时按原路展开；进度完全绑滚动位置，不自己播
- **参数**：
  - 进度 = 滚动距离 ÷ 收起距离，夹在 0–1；收起距离 = 封面高 − 导航栏高。没有时长和曲线。Web 优先 `animation-timeline: scroll()` 加 `animation-range: 0 收起距离`，用 `@supports` 检测（这个属性还没进 Baseline），不支持时退回 Motion `useScroll`。
  - 头像：`translate + scale`，`transform-origin: top left`，终点是导航栏左边、上下居中。
  - 标题：进度 60%–100%（起始值）淡入。封面里的大标题跟着页面滚走，不用单独动。
  - 毛玻璃：玻璃层一直在，取值按 `references/visual/glassmorphism.md`，滚动时只动它的 `opacity`，不改 `blur()` 半径。
  - 不改布局：导航栏 `position: fixed` 浮在上面，封面照常滚走，滚动过程中不改任何元素的布局高度。一改，页面总高跟着变，滚动位置被带着跳，这是这个效果发抖的主要原因。
- **打断**：天然跟手。
- **降级**：reduced-motion：头像不移动、不缩放，跟封面一起滚走；封面离开屏幕时，导航栏的小头像、标题、玻璃层一起淡入，200ms `--ease-out`。不支持 `backdrop-filter` 或低端 Android WebView（`references/core/platforms.md` 第 3 节）：玻璃层换成不透明底色。
- **别用在**：没有封面的页面；同一页已经用 C12（顶栏只归一个配方管）；收起距离不到 100px（起始值，变化太快，看起来像跳）；后台和工作台。
- **桌面 / 手机**：手机完整做。桌面已有常驻顶栏时，不动它，收成顶栏下面的一条窄栏（`top: var(--nav-h)`）；平板同手机。RN：只是大标题收小，用 native stack 的 `headerLargeTitleEnabled`（iOS，见 `references/build/rn.md`），不自己写；要头像时用 `useAnimatedScrollHandler` + `interpolate`，写法见 `references/build/rn-recipes.md` 的 Collapsing header on scroll；玻璃层用静态 `BlurView`，淡入它的 `opacity`，不动 `intensity`。
- **无障碍**：页面只有一个 `h1`，导航栏里的小标题 `aria-hidden="true"`。返回等按钮在封面上和收起后都要看得清：封面顶部垫一层深色渐变，图标对比度 ≥ 3:1，文字 ≥ 4.5:1。
- **相关**：C12 是把顶栏藏起来，这里是封面变成顶栏。P4 可以同页：共用一张封面，下拉归 P4。

### P11 滚动渐显

- **用在**：落地页、品牌页、对外汇报页、一次性的专题长文：人只看一次、内容一段段读的页面。
- **提示词**：内容滚进屏幕时依次上浮淡入，每块只播一次；打开页面时已经在屏幕里的内容直接显示；系统开了减弱动效时全部直接显示
- **参数**：
  - 动作：`opacity 0→1`，`translateY(16px→0)`（起始值），300ms `--ease-out`；落地页的滚动叙事可以更长，按参数词典的时长一行。
  - 错峰：同一批进屏幕的每项 50ms，总和 ≤ 300ms。按这一批里的序号错峰，不按元素在页面上的序号，不然第 30 个要等 1.5 秒。
  - 触发：全页共用一个 IntersectionObserver（一个就能看任意多个元素），`rootMargin: '0px 0px -10% 0px'`，触发后 `unobserve`，只播一次。
  - 隐藏：由脚本接上 observer 的同时，只给屏幕下方的元素加 `data-reveal="wait"`；CSS 里不写死隐藏，脚本加载失败时内容照样看得见。屏幕里和屏幕上方的元素不碰。回调里没有相交、但元素已经在屏幕上方的（恢复滚动位置时会这样），直接显示，不错峰。`@media print` 里全部显示。
  - 收尾：播完 `transform` 回到 `none`，不留 `will-change`。
  - 写法：只播一次，所以不用 `animation-timeline: view()`，那是可逆的 P2。React 用 Motion `whileInView` 加 `viewport={{ once: true, margin: '0px 0px -10% 0px' }}`；GSAP 见 `references/recipes/gsap.md`；从上往下擦出来的版本见 `references/build/web-recipes.md` 的 Scroll reveal。
  - 图片：默认跟文字一样淡入。模糊变清晰（`blur(8px)→0`，起始值）只给落地页的大图，一屏最多 1 张，低端 Android 关掉。
- **打断**：只播一次。播到一半滚走了就让它播完。
- **降级**：reduced-motion 时全部直接显示，淡入也不留。
- **别用在**：每天打开的后台、工作台、产品内列表（过不了频率关）；超过 20 项的列表、无限加载、虚拟列表（起始值；滚得快时等于一直在等内容出现）；顶栏、吸顶标签这类固定元素。
- **桌面 / 手机**：桌面同一行的卡片算一批错峰；手机单列，每块自己触发。RN / Expo：只放在介绍页、长图文，用 Reanimated `entering`，并记下播过的 id，列表回收复用时不重播；FlatList 的产品列表不加。
- **无障碍**：内容一直在 DOM 里，读屏和页内查找都不受影响。
- **相关**：内容跟着滚动位置走、能倒回去的是 P2。
