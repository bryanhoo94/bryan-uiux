# 页面级交互（P1–P8）

参数预设、曲线、手势常量和通用规则见 `references/core/params.md`，这里不重复。

### P1 捏合换密度

- **用在**：相册、作品集、商品网格这类同一批内容需要不同密度浏览的页面。
- **提示词**：给网格加双指捏合的语义，缩放，按缩放比在大图、三列、文字行三档之间切换，每一项连续移动到新位置
- **参数**：捏合过程中网格 1:1 跟手缩放；松手按当前缩放比吸到最近一档（< 0.75 切到更密，> 1.33 切到更疏，起始值）；每一项用 FLIP / layout 动画从旧位置移到新位置，`spring-ui`。Web 触控板捏合是 `wheel` 事件且 `ctrlKey === true`。
- **打断**：换档动画中再次捏合，从当前位置继续跟手。
- **降级**：三档之间直接交叉淡入（opacity 200ms `--ease-out`）。
- **别用在**：只有一种合理密度的列表。桌面端没有触控板时，另给按钮切换档位。

### P2 滚动驱动动画

- **用在**：落地页叙事段、产品介绍、onboarding 讲解。
- **提示词**：把这段动画的进度绑定滚动位置，滚动可逆，停住时动画停在对应的进度上
- **参数**：没有时长和曲线，进度 = 滚动位置线性映射到 0–1。Web 优先用 CSS `animation-timeline: view()` / `scroll()`，不支持时退回 Motion `useScroll`。
- **打断**：天然可逆，不用处理。
- **降级**：直接显示最终状态，不绑定滚动。
- **别用在**：产品内每天高频使用的页面；用户要读或要操作的数据。

### P3 速度拖影

- **用在**：图片为主的长列表或横向画廊，快速滚动时增加速度感。
- **提示词**：列表滚动时按速度给内容加方向性模糊，速度归零时平滑恢复清晰
- **参数**：模糊量跟滚动速度成正比，上限 8px（起始值）。CSS `blur()` 没有方向，方向感用 SVG `feGaussianBlur stdDeviation="0 N"`（只在滚动方向模糊）。在滚动容器上整体加一次滤镜，不要每项加；每帧用 `requestAnimationFrame` 采样速度。速度归零时模糊量用 `spring-ui` 回到 0。
- **打断**：速度实时更新，不用处理。
- **降级**：完全不加模糊。
- **别用在**：文字为主的列表（模糊后读不了）；低端 Android 设备。

### P4 下拉放大头图

- **用在**：个人主页、商品或地点详情这类顶部有大图的页面。
- **提示词**：滚动到顶，继续下拉时，顶部大图按下拉距离放大，覆盖文字同步淡出，松手带阻尼回弹
- **参数**：下拉距离先过 `rubberband`；头图 `scale = 1 + 有效距离 / 图高`，`transform-origin: top center`；图上文字 `opacity = 1 − 有效距离 / 80px`（起始值）；松手 `spring-ui` 回到原位。
- **打断**：回弹中再按住，从当前位置继续跟手。
- **降级**：不放大，只保留 G7 的到顶阻尼。
- **别用在**：没有头图的页面，用 G7。

### P5 参考线吸附

- **用在**：画布、编辑器、排版工具里拖拽元素。
- **提示词**：拖拽时检测与参考线的距离，进入阈值，自动吸附并显示对齐线，吸附瞬间给一次轻微的位移顿挫
- **参数**：进入吸附 6px、离开吸附 10px（起始值，按屏幕像素算，不随画布缩放变）。进入阈值时直接跳到对齐位置，不插值，这一跳就是顿挫。对齐线 opacity 0→1 用 100ms `--ease-out`。移动端吸附瞬间加一次轻触觉反馈。
- **打断**：元素始终跟手，吸附只修正显示位置。
- **降级**：保留吸附和对齐线，这是功能不是装饰。
- **别用在**：自由手绘、需要像素级自由摆放的场景。按住 Alt / ⌘ 时临时关闭吸附。

### P6 弧线换列

- **用在**：网格列数变化时，例如窗口变宽、切换视图、P1 换档。
- **提示词**：网格列数变化时，每一项沿弧线移动到新位置，相邻项错开延迟
- **参数**：每项 FLIP 位移；x 用 `--ease-in-out`、y 用 `--ease-out`，两条曲线不同就会走出弧线；250ms；每项错峰 30ms，项多时按行错峰。
- **打断**：动画中列数再变，从当前位置重新算目标（用 transition 或 spring，不用 keyframes）。
- **降级**：新布局直接交叉淡入。
- **别用在**：拖动窗口大小的过程中。等 resize 停下再播。

### P7 悬浮元素自动反色

- **用在**：浮在内容上的导航栏、悬浮按钮、固定 logo，页面背景深浅交替。
- **提示词**：悬浮元素按背后区域的亮度自动反色，滚动时连续过渡，不做硬切
- **参数**：简单版用 `mix-blend-mode: difference`，只适合纯黑或纯白元素。精确版给每个区块标 `data-theme="dark|light"`，用 IntersectionObserver 判断悬浮元素下方是哪个区块；两个区块交界落在悬浮元素范围内时，按交界位置比例插值颜色。两种颜色状态都要过 WCAG 4.5:1。
- **打断**：颜色随滚动连续变，不用处理。
- **降级**：颜色变化保留，它不是位移。
- **别用在**：背景是亮度不均的照片。改用半透明底板加 `backdrop-filter`。

### P8 选中项聚焦

- **用在**：横向卡片轮播、套餐或方案选择、同层级几选一。
- **提示词**：选中纵向放大提亮，同层未选中降低饱和度，并轻微缩小和模糊
- **参数**：选中卡片变高（用 layout / FLIP 动画，不要 `scaleY` 拉伸文字），`brightness(1.05)`；未选中 `scale(0.95)`、`saturate(0.6)`、`blur(2px)`（起始值）；200ms `--ease-out`。
- **打断**：transition 随时改目标。
- **降级**：保留饱和度和亮度变化，去掉缩放和模糊。
- **别用在**：未选中项还需要被阅读比较的地方，例如价格表。这种情况只降饱和度，不模糊。
