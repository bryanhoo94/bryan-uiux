### C1 重叠头像堆

- **用在**：成员、参与者、协作者列表；信息密度高的 dashboard。
- **提示词**：做一个重叠排列组件，元素互相压住三分之一，末尾显示剩余数量，点击后依次散开并显示名称，再次点击收回
- **参数**：每个元素 `margin-left: -33%`（按元素宽度）；最多显示 4–5 个，末尾放「+剩余数」。散开时每项位移用 `spring-ui`，错峰 30ms；名称在位移结束后淡入，150ms `--ease-out`。收回时从末尾开始收。
- **打断**：散开中再点，从当前位置直接收回。
- **降级**：直接切换展开和收起布局，名称只淡入。
- **别用在**：只有 1–2 个元素时，直接平铺。
- **无障碍**：触发元素是 button，带 `aria-expanded`。

### C2 进度底色填充

- **用在**：todo list、onboarding 清单、task tracker 等有明确完成度的组件。
- **提示词**：用组件背景的填充宽度表示完成进度，勾选一项时填充平滑前推，完成时整个组件轻微提亮
- **参数**：填充层用 `transform: scaleX(进度)`、`transform-origin: left`，不要动 `width`；前推 250ms `--ease-out`；全部完成时背景色变亮，200ms `ease`。可以和 F3 批量勾选接力一起用。
- **打断**：transition 自动从当前值重新算。
- **降级**：填充保留（它是状态信息），前推时长缩到 100ms。
- **别用在**：进度不确定的场景。那要用 loading 指示，不要做假进度。
- **对比度**：填充色上的文字仍要过 4.5:1。

### C3 横向手风琴

- **用在**：信息密度高的 dashboard，几个并列项要对比，但一次只看一个的详情。
- **提示词**：做一个横向手风琴组件，默认等宽窄条，点击某条展开变宽显示详情，其余同步收窄，内容延迟淡入
- **参数**：宽度用 FLIP / layout 动画，250ms `--ease-in-out`（屏幕上的形变）。详情内容延迟 150ms 后淡入，150ms `--ease-out`。收起时反过来：内容先淡出，再收窄。
- **打断**：动画中点另一条，直接转向新目标。
- **降级**：宽度直接切换，内容淡入保留。
- **别用在**：手机竖屏（窄条太窄，改用纵向折叠）；超过 6 条。
- **无障碍**：每条是 button，带 `aria-expanded`；键盘左右方向键切换。

### C4 托盘展开明细

- **用在**：卡片需要显示更多明细、又不想挤开主卡片，例如账单卡片、订单卡片。
- **提示词**：在组件下方垫一层深灰托盘，默认只露出一行，点击时托盘向下展开显示明细，主组件位置保持不动
- **参数**：托盘放在主卡片后面（层级更低），默认露出一行高度。展开时托盘高度变化，200ms `--ease-out`；用 JS 量出内容高度，不要直接动画到 `auto`。主卡片不动，托盘下方的内容被推开。明细内容淡入 150ms。
- **打断**：transition 重新算目标。
- **降级**：保留高度变化，去掉淡入以外的附加效果。
- **别用在**：明细很长时，改用抽屉或详情页。

### C5 跟手放大图标栏

- **用在**：底部工具栏、表情或反应选择、工具切换。
- **提示词**：做一排跟随手指放大的图标，按距离手指远近平滑缩放，相邻图标同步让位，松手选中当前图标
- **参数**：`scale = 1 + 0.6 × max(0, 1 − 距离 / 影响半径)`，影响半径约 2.5 个图标宽（起始值）。跟手时直接设置，不加时长。图标的实际占位要随放大变宽（用 layout 动画），否则会互相重叠。手指离开后用 `spring-ui` 回到原大小。按下就高亮、抬起才选中；移动端每经过一个图标给一次轻触觉反馈。
- **打断**：天然跟手，不用处理。
- **降级**：不放大，只高亮手指下的图标。
- **别用在**：少于 4 个图标。桌面鼠标版本要用 `(hover: hover)` 门控。

### C6 顶部摘要胶囊

- **用在**：页面顶部的统计摘要（今日花费、步数、余额），平时收起省空间。
- **提示词**：做一个可下拉展开的顶部摘要，收起时为一行胶囊，下拉时跟手展开成完整统计面板，下方内容下移并变暗
- **参数**：下拉距离 1:1 驱动展开进度 0–1；胶囊到面板用共享元素 / layout 动画形变；下方内容同步下移，遮罩 opacity 0→0.4。松手时按手势常量判断：速度够就按方向决定展开或收回，速度小才看是否过半；落位用 `spring-gesture`。超出面板高度后加 `rubberband`。
- **打断**：展开中再按住，从当前进度继续跟手。
- **降级**：改成点击切换，面板交叉淡入，不做跟手形变。
- **别用在**：页面本身已经有下拉刷新的列表。两个下拉手势会冲突，只能选一个。

### C7 搜索框就地展开

- **用在**：顶栏的搜索入口，空间不够但又不想跳页。
- **提示词**：搜索按钮点击后在原位展开成输入框，动画 300ms ease-out，展开完成后自动聚焦光标。收起时先失去焦点，再缩回按钮形态
- **参数**：宽度从按钮宽变到输入框宽，250ms `--ease-out`（宽度是布局属性，只在这种就地变形里允许）；展开动画结束后再 `focus()`，否则手机会边展开边弹键盘；收起时先 `blur()` 再缩回。
- **打断**：展开中再点，直接反向收回。
- **降级**：直接切换成输入框，不做宽度动画。
- **别用在**：搜索是主要功能的页面（那就常驻一个搜索框，不要藏）。

### C8 加号展开操作面板

- **用在**：悬浮的加号按钮（FAB），点开是几个快捷操作。
- **提示词**：悬浮加号按钮点击后从原位展开操作面板，面板内 icon 依次 stagger 出现（间隔 50ms，scale 0→1），关闭时原路收回。展开角度呈扇形或直线排列
- **参数**：面板以加号为原点展开（`transform-origin` 在加号上），`scale(0.9)` → 1 加淡入，200ms `--ease-out`；里面每个图标错峰 50ms 出现，起点 `scale(0.9)` 不是 0；关闭时反向，先收图标再收面板。加号本身转 45° 变成叉。
- **打断**：展开中再点，从当前状态收回。
- **降级**：面板直接淡入淡出。
- **别用在**：超过 5 个操作（改用底部弹层列表）。

### C9 按钮原地显示提交状态

- **用在**：提交、保存、付款按钮。
- **提示词**：按钮点击后在原位置依次变换：文字/图标 → 加载 spinner → 完成 ✓ 标记。每个状态变换用 morph 过渡而非切换，✓ 停留 1.5s 后恢复或消失
- **参数**：按钮宽度不跳变（先把宽度锁住，再换内容）；文字淡出 100ms → spinner 淡入；成功时 spinner 换成勾，勾用 SVG 路径画出 150ms，配 `spring-pop` 弹一下；勾停留 1.5 秒后回到原样。失败要换成错误态并说明原因，不能只抖一下。
- **打断**：请求期间按钮禁用，避免重复提交。
- **降级**：直接换文字（提交中 → 已提交），不做形变。
- **别用在**：耗时超过几秒的任务（那要有进度或可离开页面）。

### C10 按钮变数量步进器

- **用在**：点餐、购物车、加购数量。
- **提示词**：按钮点击后高度展开，显示出「减号 + 数字 + 加号」的步进器控件，数字滚动入场。数量归零时高度缩回，自动恢复为原按钮形态。展开高度动画 250ms ease-out
- **参数**：按钮尺寸变形 250ms `--ease-out`（用 FLIP，不要直接动 width / height）；数字用 G3 数字翻牌；归零时缩回原按钮。
- **打断**：连点加号时数字用 transition 连续更新，不重播。
- **降级**：直接切换成步进器。
- **别用在**：数量通常很大的输入（改用输入框）。

### C11 列表项就地展开详情

- **用在**：订单列表、FAQ、设置项，点开看详情但不想跳页。
- **提示词**：点击列表项后，详情区在该项位置向下展开（height 0→auto），下方列表项顺势下移。详情内容 fade in + slide up。收起时反向折叠，动画 300ms ease-in-out
- **参数**：详情高度 200ms `--ease-out`（量出内容高度再动画，别直接到 `auto`）；下方列表项跟着被推开，用 FLIP 让它们滑下去而不是瞬间跳；详情内容延迟 100ms 后淡入 + 上移 6px。
- **打断**：展开中点另一项，两个动画同时进行（要么允许多开，要么先收起旧的）。
- **降级**：高度直接切换，内容淡入。
- **别用在**：详情很长（改用详情页或抽屉）。
- **相关**：C4 托盘展开明细是「不推开别人」的版本。

### C12 顶栏随滚动收起

- **用在**：内容页的顶部导航或搜索栏，向下看内容时让出空间。
- **提示词**：向下滚动时，顶部导航栏随滚动进度逐渐缩小收起（高度、透明度、内容同步变化），向上滚动时重新展开。设置 20px 回弹阈值，小幅滚动不触发。动画跟随手指，不自动播放
- **参数**：由滚动位置驱动（同 P2），不写时长；收起进度 0→1 映射到高度、内容透明度；方向判定要有 20px 阈值，避免抖动时一直开合；到顶时永远展开。
- **打断**：天然跟手。
- **降级**：不收起，或到一定滚动距离后直接切换。
- **别用在**：顶栏里有常用操作的工具类页面（藏起来会误伤）。

### C13 菜单从按钮铺满全屏

- **用在**：手机上的全屏菜单、筛选面板。
- **提示词**：点击按钮后，背景遮罩从按钮中心位置用 clip-path circle() 向外展开铺满全屏（圆半径 0→150% 视口对角线），展开完成后菜单内容 fade in。关闭时反向收缩回按钮位置
- **参数**：`clip-path: circle(r at 按钮中心)`，r 从 0 到「按钮中心到最远角的距离」，400ms `--ease-out`（同 F1 主题扩散的算法）；菜单内容在铺满后淡入 150ms；关闭反向。
- **打断**：展开中再点，直接反向。
- **降级**：菜单整体淡入淡出。
- **别用在**：桌面端的下拉菜单（那是空间锚定的小弹层，不该占满全屏）。

### C14 两栏互换

- **用在**：换汇、币种兑换、出发地和目的地对调、翻译的源语言和目标语言对调。
- **提示词**：上下两栏中间放一个互换按钮，点一下两栏交换位置，上面那栏滑到下面、下面那栏滑到上面，按钮同时转半圈，金额跟着重算
- **参数**：两栏用 layout / FLIP 动画换位，`spring-ui`，不直接改 `top`。按钮图标转 180°，200ms `--ease-out`。金额变化用 G3 数字翻牌，或者直接换数字（数字加 `tabular-nums`）。两栏的内容跟着栏走，不要只换文字。
- **打断**：交换中再点，从当前位置反向，不排队。
- **降级**：两栏内容直接对调，交叉淡入 150ms；按钮不转。
- **别用在**：两栏字段不一样（对调没有意义）；每天点 100 次以上的工具（过频率关，直接换）。
- **桌面 / 手机**：桌面可以左右排，按钮在中间，对调是左右换位。手机上下排，按钮点击区 ≥ 44px。
- **无障碍**：按钮是 button，`aria-label` 写清现在的方向和点了会怎样（例如「现在是美元换欧元，点击对调」）；对调后用 `aria-live` 播报新方向。

### C15 图片拖动对比

- **用在**：修图前后、改版前后、两个版本的效果对比。
- **提示词**：两张同样大小的图叠在一起，中间一条竖线带一个把手，左右拖把手，线左边露出「之前」，右边是「之后」
- **参数**：上层图用 `clip-path: inset(0 X% 0 0)` 裁切，X 由把手位置算出来，1:1 跟手，不加缓动，不改 `width`。把手点击区 ≥ 44px。点图上任意位置，线移到那里，200ms `--ease-out`。初始位置 50%（起始值）。两个角上标「之前」「之后」。
- **打断**：天然跟手。
- **降级**：跟手不算动画，保留；点击后线直接跳过去。
- **别用在**：两张图构图对不上（没法比）；超过两张（改用轮播）。
- **桌面 / 手机**：桌面拖把手或点图上任意位置。手机上容器加 `touch-action: pan-y`，横向拖归把手，竖向照常滚页面；判定方向按 G4。RN 没有 `clip-path`：外层 `overflow: 'hidden'` 往左移，里面的图往右移同样的距离，两个都只动 `translateX`。
- **无障碍**：把手是 `role="slider"`，带 `aria-valuemin`、`aria-valuemax`、`aria-valuenow`，左右方向键每次移 5%（起始值）；两张图都写 `alt`。
- **现成的**：`react-compare-slider`（React，MIT）。要装先问用户。

### C16 就地确认删除

- **用在**：删除一行、移除成员、清空草稿这类不大但不想误点的操作。
- **提示词**：点删除后不弹窗，按钮自己在原地变成红色的「确认删除？」，再点一次才真的删；几秒不点就变回去；删完出现一条可以撤销的提示
- **参数**：按钮变形用 layout / FLIP，200ms `--ease-out`；文字交叉淡入 100ms（同 C9）。变成确认态后的前 300ms 不接受点击，防止连点两下误删（起始值）。4 秒（起始值）没操作自动变回。确认后这一行按 F8 飞走或直接淡出收起，同时给撤销提示（toast 用现成的，见 `references/visual/pick-library.md`）。
- **打断**：确认态下点别处或按 Esc，立刻变回。
- **降级**：文字和颜色直接切换。
- **别用在**：删了找不回来的大事（删账号、删整个项目），那种用对话框，写清后果；批量删除（用 C19 的操作条加对话框）。
- **桌面 / 手机**：两边都能用。手机上确认态的点击区 ≥ 44px；按钮变宽时往不会压到别的按钮的方向长。
- **无障碍**：始终是同一个 button，文字变了要让读屏读出来（`aria-live`）；确认态不能只靠红色，文字必须写明「确认删除」。

### C17 文件拖放上传区

- **用在**：上传图片、附件，导入表格。
- **提示词**：一个虚线框写着「把文件拖到这里，或者点击选择」；文件拖到框上方时框亮起来；放下后每个文件变成一行带进度条的条目；类型不对或者太大时，框变红并写明原因
- **参数**：拖到上方时只变边框和底色，150ms `ease`，不放大整个框。放下后条目淡入加上移 6px，200ms `--ease-out`，多个文件错峰 30ms。进度条用 `scaleX`，跟真实进度走，不放假动画。被拒绝时按 F11 的报错做法：变红、写原因（「超过 5MB」）、晃一次。Web 要在 `dragover` 里 `preventDefault()`，否则 `drop` 不触发。
- **打断**：上传中可以取消单个文件。
- **降级**：只变色，条目直接出现。
- **别用在**：只换一张头像（直接点头像换图）。
- **桌面 / 手机**：桌面支持拖入、点击选择、粘贴。手机没有拖入，整块区域就是一个按钮，点了打开系统的选文件或拍照；文案写「点击上传」，不要写「拖到这里」。
- **无障碍**：里面必须有一个真的 `<input type="file">`，点击和键盘都能用，它也是不用拖的做法；拖入、成功、失败三种状态都要有文字，不只靠颜色；上传结果用 `aria-live` 播报。
- **现成的**：`react-dropzone`（React，MIT）。要装先问用户。

### C18 签名板

- **用在**：合同、收货确认、同意书上的手写签名。
- **提示词**：一块画布，手指或鼠标在上面写，笔迹跟手，写得快的地方细、写得慢的地方粗；旁边有「撤销一笔」和「清除」
- **参数**：笔迹直接跟手，不加缓动，不加延迟。线宽跟速度走：慢 2.5px、快 1px（起始值），相邻两点之间平滑过渡。画布按 `devicePixelRatio` 放大，不然线是糊的。「清除」时笔迹淡出 150ms `--ease-out`；「撤销一笔」直接去掉最后一笔。空白时画一条签名线，写「在这里签名」。
- **打断**：天然跟手。
- **降级**：清除直接清空。
- **别用在**：不需要笔迹的确认（打勾或输入姓名就够）。
- **桌面 / 手机**：桌面用鼠标或触控板写。手机上画布加 `touch-action: none`，不然一写页面就跟着滚；画布占满屏宽，够写一个名字。
- **无障碍**：另给一个不用画的办法（输入姓名生成签名，或者上传签名图片）；「清除」「撤销一笔」是真的 button。
- **现成的**：Web 用 `signature_pad`（纯 JS，MIT），RN 用 `react-native-signature-canvas`（MIT）。要装先问用户。

### C19 选中后长出操作条

- **用在**：表格、文件列表、邮件列表的批量操作。
- **提示词**：列表里勾上第一项时，一条操作条从底部滑出来，写着「已选 1 项」和几个操作；再多选，数字跟着变；全部取消后操作条收回去
- **参数**：出现时 `translateY(100%)` 到 0 加淡入，200ms `--ease-out`；收回 150ms。只在从 0 项到 1 项、从 1 项回到 0 项时动，中间选第 2、第 3 项时条不动，只换数字（G3 数字翻牌，`tabular-nums`）。操作放 3–4 个，多的收进「更多」；只有 1 个主操作高亮。
- **打断**：收回途中又选了一项，从当前位置回来。
- **降级**：直接淡入淡出。
- **别用在**：只能单选的列表；每一行自己的操作（放在行内）。
- **桌面 / 手机**：桌面浮在列表区域底部居中，列表底部留出一条的高度，不挡最后一行。手机贴底，避开 `env(safe-area-inset-bottom)`；页面有底部 Tab 时，操作条出现期间顶替 Tab。
- **无障碍**：操作条是 `role="toolbar"`；数量变化用 `aria-live="polite"` 播报；Esc 取消全部选择；里面的删除要先确认（批量用对话框，不用 C16）。
