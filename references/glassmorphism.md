# 玻璃质感（Apple 风磨砂卡片）

排版方向 L1（方格纸 + 玻璃卡）定的是「结构」，这份定的是「玻璃具体怎么做」。

## 先别急着用

- **玻璃要有东西可透才成立**：底下得有方格纸、照片或彩色区块。纯白底上做玻璃 = 白白浪费一层性能。
- **半透明玻璃 + 紫粉渐变（`#667eea → #764ba2` 这类）是 AI 生成页面最常见的配色**，照抄一眼就被看出来。玻璃可以用，**强调色一定换成项目自己的**。
- **项目已经有 `DESIGN.md`** → 用项目的颜色和圆角，这里的取值只在从零开始时用。
- **低端 Android 和 WebView 上 `backdrop-filter` 很贵**（见 `platforms.md`），要准备降级成不透明卡片。

## Token

| 项 | 取值 |
|---|---|
| 卡片圆角 | 24–32px（小组件 12–16px） |
| 卡片底色 | `rgba(255,255,255,0.65~0.85)` |
| 模糊 | `backdrop-filter: blur(20–40px)`，Safari 要加 `-webkit-backdrop-filter` |
| 阴影 | `0 12px 40px rgba(0,0,0,.06)`, `0 4px 12px rgba(0,0,0,.04)`（大面积柔和，不要硬边） |
| 边框 | `1px solid rgba(255,255,255,0.3)`，或者不要 |
| 内边距 | 20–28px |
| 页面底色 | 浅灰渐变 `#F5F5F7 → #EFEFEF`，或配 L1 的方格纸 |

```css
.glass-card{
  background: rgba(255,255,255,.75);
  backdrop-filter: blur(24px); -webkit-backdrop-filter: blur(24px);
  border-radius: 28px; border: 1px solid rgba(255,255,255,.3);
  box-shadow: 0 12px 40px rgba(0,0,0,.06), 0 4px 12px rgba(0,0,0,.04);
  padding: 24px;
}
@media (prefers-reduced-transparency: reduce){
  .glass-card{ background:#fff; backdrop-filter:none; -webkit-backdrop-filter:none; }
}
```

## 几个现成组件

| 组件 | 要点 |
|---|---|
| 悬浮 Tab Bar | 固定在底部居中，玻璃底 `rgba(255,255,255,.85)` + `blur(32px)`，圆角 20px，内边距 12px，项间距 8px；手机上要留安全区 `env(safe-area-inset-bottom)`。切换动效用 M5 |
| 阶梯指标卡 | 三张卡按数值高低排出阶梯（高度差 24px 一档），底部对齐；三档填充：实心 → 斜纹（`repeating-linear-gradient` 45°）→ 浅色。同 L1 的材质分层 |
| 分段比例条 | 一条横贯整行，高 12px，圆角 6px，段间 2px 细缝，宽度按比例；点击某段抽出显示名称和占比 = D8 |
| 渐变面积图 | SVG，面积用 `linearGradient` 从强调色 0.4 透明度渐到 0.1，线条 2px 实色。切换周期时的形变用 D6 |
| 欢迎卡 / 首屏卡 | 一张大玻璃卡装主视觉，卡内再放一颗药丸形控制条（图标 + 文字 + 开关） |

## 整页提示词

**Dashboard 首页**：做一个 Apple 风格的磨砂玻璃 Dashboard：页面底色浅灰渐变；卡片半透明白玻璃（blur 24px），圆角 28px，柔和阴影；顶部一排指标卡按数值排成阶梯，第一块实心、第二块斜纹、第三块浅色；底部悬浮玻璃 Tab Bar；全页只用一个强调色。

**行程卡片**：顶部深色卡片放航班信息（白字），下面玻璃卡片放座位和到达时间，卡片间距 16px，整体浮在浅灰底上，底部五个图标的 Tab Bar。

**兴趣选择（新手引导）**：纯白底，中间一张玻璃卡；标题 48px 字重 200；兴趣标签是胶囊形，未选浅灰底、选中深底白字；底部显示「已选 1/3」和下一步按钮；留白宽松。

**深色金融卡片**：底色 `#0A0A0A`，卡片 `#16161A` 不描边；余额 56px 白字，涨跌用绿色；面积图用强调色渐变；按钮是药丸形。（这套属于 L4，不要再叠玻璃）

## 配套交互

- 卡片悬停抬起、旁边让位 → E1（桌面才做，包在 `hover: hover` 里）
- 选中某张卡放大提亮 → P8
- 卡片入场 → 错峰淡入 + 上浮，别让玻璃卡从零放大

## 常见翻车

- ❌ 透明度调到 1 → 变成实心卡，玻璃感没了。
- ❌ `blur` 小于 10px → 底下透上来的东西是糊的杂色，不是质感。
- ❌ 阴影又黑又硬 → 变成 Material 风，不是 Apple 风。
- ❌ 圆角小于 16px → 失去柔和感。
- ❌ 强调色超过一个色系 → 和玻璃打架，画面变杂。
- ❌ 玻璃卡上的文字对比度不够 → 背景一花就读不了。文字和底色对比度仍要 ≥ 4.5:1，必要时在文字下垫一层半透明底。
- ❌ 满屏都是玻璃 → 玻璃是用来突出「浮起来的那一层」的，全都浮起来等于都没浮。
