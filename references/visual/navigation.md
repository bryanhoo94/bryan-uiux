主导航只设计一次：**同一组入口、同一个顺序、同一种选中样式**，在手机、平板、桌面上换三种摆法。只做了手机底部 Tab、没说桌面怎么排，不算完成。

时长、曲线、spring 见 `references/core/params.md`；项目有 `DESIGN.md` 或已有导航，就用项目的颜色、圆角和图标，这里只补缺的视图。

规范依据：Apple HIG「Tab bars」、Material 3「Navigation bar」（2026-09-27 核对）。

## 先定三件事

1. **有几个入口**：底部 Tab 放 3–5 个（Apple 和 Material 都是这个范围）。
   - 只有 2 个 → 不用底部 Tab，用顶部分段控件。
   - 超过 5 个 → 先砍，再把低频的并进「我的」页或设置页。「更多」Tab 是最后手段：Apple 明确建议避免，藏进去的入口很少有人点。
   - 桌面侧边栏不受 5 个的限制，入口多就分组（`references/visual/dashboard-layouts.md` 的 L2）。
2. **平台习惯**：原生 iOS、原生 Android、Web 各有默认样子（见下面「怎么挑风格」第 2 条）。用户习惯了什么就给什么（`references/ux/ux-laws.md` 的雅各布定律）。
3. **有没有一个核心动作**：发布、新建、拍照这类。有的话，它**不占 Tab 位**，单独做一个主按钮（见风格 6）。Apple 规定 Tab 栏只放导航、不放动作。

## 三种宽度怎么摆

断点先用项目已有的；没有就用 `references/core/platforms.md` 第 2.2 节的：手机 < 640px ｜ 平板 640–1023px ｜ 桌面 ≥ 1024px。

```
手机 <640px          平板 640–1023px        桌面 ≥1024px
┌────────────┐       ┌──┬─────────┐        ┌────────┬─────────┐
│            │       │▣ │         │        │ Logo   │         │
│    内容    │       │○ │  内容   │        │ ▣ 首页 │  内容   │
├────────────┤       │○ │         │        │   订单 │         │
│ ▣首页 ○ ○ ○ │       │○ │         │        │   设置 │         │
└────────────┘       └──┴─────────┘        └────────┴─────────┘
 底部 Tab               左侧图标竖栏            侧边栏
```

| | 手机：底部 Tab | 平板：图标竖栏 | 桌面：侧边栏（或顶栏） |
|---|---|---|---|
| 位置 | 固定在屏幕底部 | 固定在左边，宽 80px（起始值） | 左边，宽 240–280px（起始值），可以收起成竖栏；入口 ≤ 5 的内容型网站（电商、博客）也可以用顶栏 |
| 入口 | 3–5 个 | 跟手机一样 | 全部入口，按组排 |
| 文字标签 | 在图标下方 | 在图标下方 | 在图标右边 |
| 选中样式 | 三种宽度用**同一种**（同样的胶囊、指示条或填充） | ← | ← |
| 核心动作 | 单独的悬浮按钮，或页面里的主按钮 | 竖栏最上面一个按钮 | 侧边栏最上面一个主按钮（「+ 新建」） |
| 安全区 | 底部 `env(safe-area-inset-bottom)` | 横屏时左边 `env(safe-area-inset-left)` | 不用 |

- 平板竖屏也可以直接用手机的底部 Tab；横屏用竖栏。
- 桌面 App（Electron / Tauri）用侧边栏；窗口拖窄以后换成竖栏，再窄换成底部 Tab。
- RN / Expo 用 `useWindowDimensions()` 读宽度来切换，不要按设备型号写死。

## 5 条硬规则

原始清单有几条跟平台规范对不上，这里是改过的版本。

1. **入口 3–5 个。** 超过 5 个按上面「先定三件事」第 1 条处理。
2. **点击区够大**：iOS ≥ 44 × 44pt，Android ≥ 48 × 48dp，Web ≥ 44 × 44px。整格都能点，不是只有图标能点。
3. **选中和没选中至少有 2 处不同**：颜色之外，再加形状（胶囊、指示条）、图标填充或字重其中一样。只靠颜色，色弱的人分不出来。选中项的图标对比度 ≥ 3:1，文字 ≥ 4.5:1。
4. **同一套图标、同样的笔画粗细。** 选中时换成**同一款的实心版**可以，这不算混风格。Apple 在 iOS 上倾向用实心图标。
5. **切换不加动画。** Tab 每天点上百次，过不了 频率关。只做按下反馈（100–160ms，变透明或轻微缩小），选中状态立刻换好。M5 流动 Tab 只给「有弹性」人格的消费 App 用。

## 11 种风格

| # | 风格 | 手机长什么样 | 平板 / 桌面长什么样 | 适合 | 注意 |
|---|---|---|---|---|---|
| 1 | 极简 Minimal Clean | 纯色底，图标 + 文字，细线图标 | 侧边栏同色底，不加卡片和阴影 | 工具、后台、信息多的产品 | 选中差异容易太弱：加主色 + 加粗，凑够 2 处不同 |
| 2 | 磨砂玻璃 Glassmorphism | 半透明磨砂底，内容从后面透出来 | 侧边栏或顶栏同样磨砂 | 背后有照片、视频的内容产品 | 做法见 `references/visual/glassmorphism.md`；低端 Android 关掉模糊；在最亮的背景上测文字对比度 |
| 3 | 悬浮 Floating Detached | 离底边 12–20px、左右缩进，圆角，带阴影 | 侧边栏离窗口边 12px，圆角浮起 | 高端、付费产品 | 距离要**加在安全区之上**；内容底部留出同样高度，别被挡住 |
| 4 | 新拟物 Neumorphism | 浅色底，软阴影做出凸起和凹陷 | 同上 | **慎用** | 按钮边界很难达到 3:1 对比度，默认不用 |
| 5 | 胶囊 Pill Highlight | 选中项有一块圆角胶囊底色 | 侧边栏选中那一行整行胶囊底色 | 通用、电商；Android Material 3 默认就是它（胶囊 56 × 32dp） | 胶囊用主色浅底 + 主色图标，不用红色（红色留给错误和角标） |
| 6 | 中间大按钮 Center FAB | 中间一个 56px 圆形按钮，左右各 2 个入口 | 侧边栏最上面一个「+ 发布」主按钮 | 核心动作是发布、创建的产品 | iOS 上 Tab 栏只能放导航：中间按钮要打开一个「发布」**页面**，或者干脆拿出 Tab 栏做成单独的悬浮按钮。全屏只能有 1 个悬浮按钮。展开成几个选项用 C8 |
| 7 | 渐变 Gradient Bold | 渐变底色 | 侧边栏渐变底 | **慎用**：年轻、娱乐、健身 | 在渐变最浅的地方测图标和文字对比度；项目有 `DESIGN.md` 就按项目的 |
| 8 | 线框变实心 Outline → Filled | 没选中是线框图标，选中换成同款实心 | 同上 | 阅读、内容、极简产品 | 图标库要同时有线框和实心两版（SF Symbols、Material Symbols、Phosphor 有；Lucide 只有线框） |
| 9 | 指示条 Tab with Indicator | 选中项下方（或上方）一条 2–3px 短条 | 侧边栏选中行左边一条 3px 竖条 | 通用，最稳 | 短条只算 1 处不同，还要配主色 |
| 10 | 圆角顶 Curved Background | 导航栏顶部两个角做 16–24px 圆角 | 侧边栏不做，或只做右上角 | 想要柔和一点的产品 | 圆角外面露出的内容要处理好，别出现一截白边 |
| 11 | 仿 iOS Dock | 悬浮 + 磨砂 + 24px 大圆角 + 离边 12px，接近 iOS 26 起的系统 Tab 栏 | 悬浮的磨砂侧边栏 | 以 iPhone 用户为主的产品 | 就是 2 + 3 的组合，两边的注意事项都要守 |

## 怎么挑风格

原始清单是「电商 + 高端 → 胶囊」这种写死的规则，那只是口味。改成按下面顺序挑：

1. **项目已经有导航或 `DESIGN.md`** → 照项目的，只补缺的那种宽度。
2. **平台默认**最不会错：原生 iOS 用系统 Tab 栏（≈ 11）；原生 Android 用 Material 3（≈ 5）；Web 应用用 9 或 5。
3. **按动效人格**（`references/core/pick.md`）：克制 → 1、9、5；有弹性 → 5、8、3，可以配 M5；有表现力 → 2、3、11，慎选 7。
4. **有核心动作** → 加上风格 6 的「单独主按钮」做法，跟上面任何一种都能搭。
5. 出 2–3 套方案时（`references/ux/interview.md`），每套写明风格编号，并画出手机、平板、桌面三种样子。

## 尺寸和安全区

| | 高度 | 图标 | 文字 |
|---|---|---|---|
| iOS 原生 | 用系统 Tab 栏，不自己算 | SF Symbols | 系统字号 |
| Android 原生 | Material 3：80dp；M3 Expressive：64dp | 24dp | 系统字号 |
| Web / WebView | 56–64px（起始值）+ 底部安全区 | 24px | 12px 起 |

**安全区不要写死 34px。** 每台手机不一样：iPhone SE 是 0，横屏也会变。

Web：

```html
<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">
```

```css
/* 没有 viewport-fit=cover，iOS 上 env() 永远是 0 */
.tabbar {
  position: fixed; left: 0; right: 0; bottom: 0;
  padding-bottom: env(safe-area-inset-bottom);
  display: grid; grid-auto-flow: column; grid-auto-columns: 1fr;
}
.tabbar a { min-height: 56px; display: grid; place-items: center; } /* 整格可点 */
main { padding-bottom: calc(56px + env(safe-area-inset-bottom)); } /* 内容不被挡住 */

@media (min-width: 640px)  { /* 平板：换成左侧竖栏 */ }
@media (min-width: 1024px) { /* 桌面：换成侧边栏 */ }
```

RN / Expo：

```tsx
const { width } = useWindowDimensions();
const insets = useSafeAreaInsets(); // react-native-safe-area-context
const layout = width >= 1024 ? 'sidebar' : width >= 640 ? 'rail' : 'tabs';
// 自己画 Tab 栏时：paddingBottom: insets.bottom
```

用 Expo Router 的 `Tabs` 或 React Navigation 的 bottom tabs 时，安全区已经处理好了，不要再加一次。

## 动效

- **按下**：100–160ms，变透明或轻微缩小。每次点都有回应，但不拖慢。
- **切换选中**：颜色和填充立刻换，最多 150ms `ease` 过渡。「有弹性」人格可以给指示器用 M5 流动 Tab。
- **切换页面内容**：不做左右滑动的转场。Tab 之间是平级的，不是前进或后退。
- **往下滚动时**：不要把 Tab 栏整个藏起来（Apple：藏起来人会忘了自己在哪一区）。想省空间，iOS 风可以缩小，顶栏收起用 C12。
- **角标出现**：可以用 `spring-pop` 弹一次，只在数字从 0 变成有的时候弹。
- **reduced-motion**：M5 的拉伸去掉，指示器直接换位置。

## 无障碍

- Web：`<nav aria-label="主导航">`，当前项加 `aria-current="page"`。RN 自己画的 Tab：`accessibilityRole="tab"` + `accessibilityState={{ selected: true }}`。
- 一定要有文字标签。只放图标时，每个图标都要有 `aria-label` 或 `accessibilityLabel`。
- 字号跟着系统设置走，放大到 200% 时标签不重叠（可以截成省略号，但可读的名字保留全称）。
- 桌面侧边栏：Tab 键能走到每一项，Enter 进入，当前焦点有明显的框。
- 读屏顺序跟看到的顺序一致：手机从左到右，侧边栏从上到下。

## 例子

**电商 App**（消费产品，有弹性人格；4 个入口：首页、分类、购物车、我的）
- 手机：5 胶囊，选中项主色浅底 + 主色实心图标，购物车上有数字角标。
- 平板：左侧竖栏，同样的胶囊。
- 桌面：顶栏。Logo 在左、搜索在中间、购物车在右上角，跟用户在别的购物网站看到的一样。

**社交 App**（核心动作是发布；4 个入口：首页、发现、消息、我的）
- 手机：4 个 Tab + 右下角一个单独的「+」悬浮按钮，不占 Tab 位。一定要放在中间（风格 6）的话，点了打开「发布」页面，不要弹出菜单。
- 平板：竖栏最上面是「+」，下面 4 个入口。
- 桌面：左侧边栏，最上面是主色的「+ 发布」按钮，下面 4 个入口。

## 别这样做

- 入口超过 5 个还硬塞进底部 Tab。
- 在 Tab 栏里放「发布」「分享」这类动作（除非点了会打开一个页面）。
- 禁用或隐藏某个 Tab。那一区没内容，就在页面里说明原因（Apple 的建议）。
- 选中和没选中只差颜色。
- 同一栏混用两套图标。
- 一屏超过 1 个悬浮按钮。
- 只做了手机，桌面直接把底部 Tab 拉宽。
