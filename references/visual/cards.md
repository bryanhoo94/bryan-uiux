这组卡片显得高级，靠三件事：**配色克制、信息层级清楚、微交互细致**，不靠堆装饰。

参数预设、曲线和通用规则见 `references/core/params.md`，这里不重复。

## 先别急着用

- **项目已经有 `DESIGN.md`** → 用项目的颜色、圆角和字号，这里只借结构和层级。这里的取值只在从零开始时用。
- 要做玻璃质感 → 看 `references/visual/glassmorphism.md`，不要在这套卡片上再叠一层玻璃。

## 配色（最重要）

**一张卡片只用一种主色。** 主色是视觉重心，其余全部用黑白灰。

| 卡片底色 | 主色 | 文字 |
|---|---|---|
| 深色底 | 一个够亮的强调色，从项目品牌色里取。别默认用紫 / 蓝霓虹，那是模板 AI 页的标志；品牌色本来就是紫才用紫 | 白色，层级靠透明度：100% / 70% / 60% / 50% |
| 浅色底 | 品牌色或柔和色 | 深灰，见下方「字号层级」 |
| 图片卡 | 从图片里取一个颜色做点缀 | 跟随卡片底色 |

**图片占卡片面积不超过 40%**，文字区至少 60%。图片只是氛围，信息才是主角。

## 卡片结构

| 项 | 浅色版 | 深色版 |
|---|---|---|
| 圆角 | 24–32px | 24–32px |
| 背景 | `#FAFAFA` 或 `#F5F5F7` | `#0D0D0F` 或 `#111114` |
| 内边距 | 20–24px | 20–24px |
| 阴影 | `0 4px 24px rgba(0,0,0,0.06)` | `0 4px 24px rgba(0,0,0,0.2)` |
| 边框 | 无 | 无，卡片比页面底亮一档（明度差 1–3%）就分得开 |

**图片嵌入版**：圆角 24–32px；图片在顶部，占 40%，跟着卡片圆角一起裁切；文字在底部，占 60%，内边距 20px。

## 字号层级（浅色版）

| 元素 | 字号 | 字重 | 颜色 |
|---|---|---|---|
| 标题 | 18–22px | 600–700 | 主色或 `#111` |
| 副标题 | 14–16px | 400 | `#666` |
| 正文 | 13–14px | 400 | `#6E6E73` |
| 标签 / 徽章 | 11–12px | 500 | 主色或白色 |
| 辅助信息 | 10–12px | 400 | `#6E6E73` |

原稿的正文用 `#888`、辅助信息用 `#AAA`，在浅底上对比度最多只有 3.4:1 和 2.2:1，不到 WCAG AA 要求的 4.5:1，所以都换成了 `#6E6E73`（在两种浅底上是 4.7–4.9:1）。深色版的白字按上面的透明度，最浅一档 50% 也有 5.3:1。正文和辅助信息之间靠字号拉开层级，不靠把字调浅。

## 视觉焦点放哪

- **金额 / 核心数字**：放在上半区，32–48px，用主色。数字会变就配 G3 数字翻牌。
- **头像组**：圆形头像横排，间距 -4px（轻微重叠），放在标题旁边或卡片顶部。点开要散开显示名字就用 C1。
- **按钮 / CTA**：胶囊形，用主色实心填充。
- **进度条 / 波形**：细线，用主色，放在卡片底部。

## 6 种现成卡片

| 卡片 | 用在 | 结构 |
|---|---|---|
| 头像组 + 金额 | 社交金融 | 顶：4–5 个重叠头像 + 标签 ｜ 中：超大金额（32–48px / 600 / 主色）｜ 底：Receive / Send 两个胶囊按钮，主要的那个主色实心，另一个描边（一张卡只有 1 个实心按钮） |
| 内容卡片 | 推荐、社交 | 顶：标题 + 胶囊标签 ｜ 中：摘要 2–3 行，14px，正文色 ｜ 底：Join 主色实心 + Explore 描边，旁边是互动数据（点赞数、成员数） |
| 图片 + 文字 | 旅行、音乐、生活方式 | 顶部 40%：铺满的图片，圆角裁切 ｜ 底部 60%：标题 + 地点或描述 + 指标（km / 时长 / 评分） |
| 个人资料 | 服务、freelancer | 顶：封面图，圆形头像压在封面左下角，带描边 ｜ 中：名字 + 一句话简介 + 在线状态点 ｜ 底：数据格（评分 / 收入 / 时薪）+ CTA 按钮 |
| 音频波形 | 播客、音乐 | 左：圆形头像 + 名字 + 发布时间 ｜ 中：主色线条的波形 + 播放量（如 50.1k）｜ 右：点赞 / 评论 / 分享 |
| 逐条处理 | 审核新发件人、审批、一条条过合同条款、导入时确认重复数据 | 顶：标题 + 数量胶囊 + 关闭 ｜ 可选：线稿插画 ｜ 中：一句话 + 「1 / 12」+ 分段进度条，下面是当前这一条 ｜ 底：左「稍后」，右「拒绝」+「允许」。详见下一节 |

### 逐条处理卡

一批同类的东西要人一个个点头。一次只给看一条，看完就决定，进度一直看得见。

**用不用（自己判断，不问用户）**

| 项目里看得到的 | 用不用 |
|---|---|
| 有一批「待确认」的数据（新发件人、待审批单、AI 改过的条款、导入时疑似重复的记录），每条看一张卡的信息就能决定 | 用 |
| 每条要跟很多条并排比较，或者用户习惯一口气全选处理 | 不用。用表格，勾选后用 C19 长出批量操作条 |
| 只有 1 条要确认 | 不用。直接用确认弹窗 |

**从上到下**

| 区 | 做法 |
|---|---|
| 顶栏 | 图标 + 标题 + 数量胶囊（「12 条新的」）+ 关闭按钮 |
| 插画（可选） | 第一次打开或在引导里才放，占卡片高度 35–40%，画法按 `references/visual/illustrations.md`。老用户每天打开的那张不放 |
| 一句话 + 进度 | 左边一句话讲这批是什么（「12 个新发件人想进来」），右边「1 / 12」，用 `tabular-nums`。下面是分段进度条，一条一段，处理过的段用强调色；超过 20 条（起始值）改成一根连续进度条 |
| 当前这一条 | 头像 + 名字 + 状态胶囊（「已验证」用状态色绿，不算强调色）；正文预览往下沉一档（深色版用页面底色，见 L4 灰阶）；最后一行放 2–3 个帮你决定的事实（「第一次来信：今天 ｜ 来往过：0 次 ｜ 在通讯录：否」） |
| 按钮 | 左边「稍后」纯文字；右边「拒绝」灰底、「允许」强调色实心。一张卡只有一个实心强调色按钮。拒绝能撤回就用灰底，不用红；删了找不回来的才用红 |

**动效**

- 换下一条：只换中间「当前这一条」，交叉淡入淡出 200ms `--ease-out`。整张卡不飞走，一次要过十几条，飞来飞去会烦。
- 进度条那一段变成强调色：200ms `ease`。
- 一天要过 100 条以上的（客服工单、审核员）：频率关，不做淡入，直接换。
- 「稍后」不算处理，进度不前进，这一条排到最后。
- 全部处理完：卡片内容换成空状态，用 `references/visual/illustrations.md` 的「全部处理完」，勾画出来一次。
- reduced-motion：保留淡入淡出（它只是透明度），其余照旧。

**桌面和手机**

| 项 | 桌面视图 | 手机视图 |
|---|---|---|
| 放在哪 | 居中弹窗，宽 480px（起始值） | 底部弹层，宽 = 屏宽；屏幕高度不到 700px（起始值）就不放插画 |
| 按钮 | 一行：左「稍后」、右「拒绝」「允许」 | 「拒绝」「允许」平分一整行，≥ 44px 高；「稍后」放到它们上面一行，纯文字 |
| 键盘 | 每个按钮带快捷键，按钮上显示键位（例如 `A` 允许、`X` 拒绝、`L` 稍后，起始值，先对齐项目已有的快捷键） | 不显示键位 |
| RN / Expo | — | 底部弹层用项目已有的 bottom sheet；按钮按下反馈按 `references/build/rn.md` |

- 无障碍：「1 / 12」写成读屏能听懂的「第 1 条，共 12 条」（`aria-label`）；换下一条后，焦点回到这一条的名字上，读屏会读出新的内容。

## 微交互

| 交互 | 做法 |
|---|---|
| 卡片悬停 | `translateY(-4px)` + 阴影加深，200ms `--ease-out`。加深的阴影放在 `::after` 伪元素上，只动它的 `opacity`，不要直接改 `box-shadow`。包在 `@media (hover: hover) and (pointer: fine)` 里 |
| 按钮按下 | `scale(0.96)`，100ms `--ease-out` |
| 图片加载 | 先放浅灰骨架屏占位，图片加载完成后淡入（`opacity`，≤ 300ms `--ease-out`） |
| 标签胶囊悬停 | 背景色加深 10%，150ms `ease` |

悬停时还要让旁边的卡片让开，用 E1；删除卡片用 F8；卡片堆叠滚动用 F9。

## 桌面和手机

同一张卡片在两种视图里只改尺寸和排法，配色和层级不变。通用的布局变法见 `references/core/platforms.md` 第 2.2 节。

| 项 | 桌面视图 | 手机视图 |
|---|---|---|
| 排法 | 多列网格 | 1 列，卡片宽 = 屏宽 − 2 × 16px；同类推荐可以横滑一排，露出下一张的一截 |
| 圆角 | 24–32px | 20–24px |
| 内边距 | 20–24px | 16–20px |
| 金额 / 核心数字 | 48px | 32px，中间用 `clamp(32px, 6vw, 48px)` 过渡 |
| 标题 | 22px | 18px |
| 正文 / 辅助信息 | 13–14px / 10–12px | 14px / 不小于 11px |
| 悬停抬起 | 做 | 不做。整张卡可点时改成按下反馈：`scale(0.98)`，100ms `--ease-out`（起始值） |
| 按钮 | 按内容宽 | 可点区域 ≥ 44px 高；卡片底部的两个按钮平分一整行 |

**RN / Expo**

- 阴影：iOS 用 `shadowColor` / `shadowOffset` / `shadowOpacity` / `shadowRadius`，Android 用 `elevation`；新架构（RN 0.76 起）也可以直接写 `boxShadow`。
- 没有 hover，也没有 `::after`。按下反馈用 `Pressable` + Reanimated，具体写法见 `references/build/rn.md`。
- 图片跟着圆角裁切要用 `overflow: 'hidden'`，但 iOS 上它会把同一层的阴影一起裁掉。阴影放在外面再包一层。

## 常见翻车

- ❌ 一张卡片里出现两种以上主色 → 变成调色盘。
- ❌ 圆角小于 16px → 失去柔和感。
- ❌ 图片铺满整张卡片，不给文字留位置 → 变成图片展示，不是信息卡片。
- ❌ 所有文字同一个字号 → 没有层级，用户不知道先看哪里。
- ❌ 不透明的实线边框（例如 `1px solid #E5E5E5`）和阴影同时出现 → 二选一。深色版也不画边：黑底上阴影几乎看不见，靠卡片比页面底亮一档分开（质感 10 条第 1 条，`references/visual/premium-details.md`）。
