# 图表控件交互（D1–D10）

参数预设、曲线、手势常量和通用规则见 SKILL.md，这里不重复。

**图表额外规则**

- 进入动画（画出、数字增长）每个会话只播一次；之后只在数据变化时播。dashboard 一天打开几十次，每次都从零画会很烦。
- 进入绘制 300–500ms，按全屏切换那一档。
- 动画只能帮助看懂，不能改变数据的样子：比例、面积、刻度必须和数据一致。
- 屏幕阅读器读的是最终值（写在 `aria-label` 里），不是动画中的数字。
- 颜色不能是唯一的区分方式，要配标签或图例。配色交给 `dataviz` skill。

### D1 同心活动圆环

- **用在**：多个目标的完成度，例如运动三环、预算 / 收入 / 储蓄三个目标。
- **提示词**：做一组同心活动圆环，进入时从零画到当前值，中心数字同步增长，超出目标部分叠加深色
- **参数**：SVG 圆环用 `stroke-dashoffset` 从 0 画到当前值，400ms `--ease-out`，三个环错峰 50ms。中心数字和圆环用同一个进度插值。超过 100% 的部分从起点再画一圈，用同色加深。
- **降级**：直接显示最终值，数字不滚动。
- **别用在**：超过 3 个目标，改用 D8 分段占比条或柱状图。
- **无障碍**：例如 `aria-label="步数 8,200 / 10,000（82%）"`。

### D2 打卡热力格

- **用在**：习惯打卡、活跃度、每日记账次数。
- **提示词**：做一个打卡热力格，按次数分五档深浅，点击某一天弹出当天详情
- **参数**：5 档 = 0 次一档，其余按分位数分 4 档；不要平均切，否则一两天的极值会把其他天都压成浅色。同一色相的明度阶梯。点击弹出小弹层，150–200ms `--ease-out`，`transform-origin` 在被点的格子上。今天的格子加描边。
- **降级**：弹层只淡入，不缩放。
- **别用在**：数据只有几天的时候，格子太空，改用列表。
- **无障碍**：每格是 button，例如 `aria-label="9月3日：2次"`。

### D3 半圆仪表盘

- **用在**：一个指标落在哪个区间，例如报税进度、预算使用率、健康分。
- **提示词**：做一个半圆仪表盘，刻度分三段颜色，指针进入时扫到当前值，带轻微回弹
- **参数**：三段 = 正常 / 注意 / 超标，分界值由业务决定，不是三等分。指针用 `rotate`，`transform-origin` 在圆心，用 `spring-gesture`（自带轻微回弹）。每段加文字标签，不只靠红黄绿区分。
- **降级**：指针直接指向最终值。
- **别用在**：没有明确区间含义的指标。

### D4 周 / 月切换柱状图

- **用在**：按周或按月看统计，例如支出、收入、时长。
- **提示词**：做一个柱状图，切换周和月时柱高平滑过渡，按住某根时其余变暗并显示数值
- **参数**：柱高用 `scaleY`，`transform-origin: bottom`；切换 250ms `--ease-in-out`，y 轴刻度同步过渡。周（7 根）和月（30 根）柱数不同，不要硬配对，旧柱组淡出、新柱组淡入长高。按住某根：其余柱 opacity 降到 0.4，150ms；数值显示在柱顶。手指左右滑动可以切换到相邻的柱子。
- **打断**：transition 重新算目标。
- **降级**：切换时直接交叉淡入。
- **无障碍**：每根柱可以用键盘聚焦并读出数值。

### D5 专注分段图

- **用在**：一天中各阶段的分布，例如专注 / 休息、睡眠阶段、营业时段。
- **提示词**：做一个专注分段图，按阶段区分高度和颜色，横向滑动时顶部显示当前时刻和阶段
- **参数**：阶段同时用高度和颜色区分（色盲也能看）。横向滑动时一条竖线 1:1 跟手，顶部标签显示如「14:32 · 深度专注」，标签跟着竖线走但不超出图表边界。移动端每跨过一个阶段给一次轻触觉反馈。松手后标签 150ms 淡出。
- **降级**：保留，跟手不是装饰。
- **别用在**：超过 5 种阶段。

### D6 周期切换折线图

- **用在**：趋势按一周 / 一月 / 一年切换。
- **提示词**：做一个折线图，顶部切换一周/一月/一年，线条平滑变形到新数据，面积渐变同步过渡
- **参数**：点数不同时，先把两组数据重采样到相同点数再插值路径，否则线会乱扭。250ms `--ease-in-out`；面积和线用同一个插值；y 轴范围同时过渡。顶部切换器用滑动指示条（`animate` RECIPES 里的 Tab indicator）。
- **降级**：直接交叉淡入。
- **别用在**：前后数据形状差太多、变形没意义时，直接淡入。

### D7 可拖动目标线柱状图

- **用在**：设定目标或预算线，看几天达标。
- **提示词**：做一个带可拖动目标线的柱状图，拖动时过线的柱子高亮，顶部实时显示达标天数
- **参数**：目标线 1:1 跟手，吸附到整数刻度（吸附方式同 P5：进入 6px、离开 10px）。过线的柱子换色，150ms `ease`。达标天数直接更新，不做滚动动画（拖动时滚动会晃）。目标线上下各扩出热区，总高 44px。
- **降级**：保留，这是功能。
- **无障碍**：目标线用 `role="slider"`，键盘上下键调整。

### D8 分段占比条

- **用在**：构成或占比，例如支出分类、时间分配。比环形图省空间。
- **提示词**：做一条分段占比条，段间留细缝，点击某段时抽出并显示名称和百分比
- **参数**：段与段之间留 2px 缝。点击的段上移 4px（起始值），150–200ms `--ease-out`；名称和百分比显示在段上方的小弹层里。再点一次或点别处收回。
- **别用在**：超过 6 段。太小的段点不中，合并成「其他」。

### D9 环形占比图

- **用在**：占比，而且中心需要显示总数或当前焦点。
- **提示词**：做一个环形占比图，各段依次顺时针画出，点击某段外移高亮，中心显示该段名称和占比
- **参数**：各段依次画出，总时长 ≤ 500ms，按占比分配每段时长（不是每段一样长）。点击的段沿自己的中心角方向外移 6px（起始值），150ms `--ease-out`；中心文字交叉淡入 150ms。
- **降级**：直接显示完整环形。
- **别用在**：超过 6 段；需要精确比较相近占比时，改用柱状图。

### D10 气泡图

- **用在**：数量对比，并且想要一点趣味，例如标签热度、分类数量。
- **提示词**：做一个气泡图，圆的大小表示数量，点击某个气泡放大居中，其余气泡被推开
- **参数**：**面积**和数量成正比（半径 = √数量）。如果让半径和数量成正比，大的会被夸大。布局用圆堆积或力导向（d3-hierarchy `pack` / d3-force）。点击后目标气泡用 `spring-gesture` 移到中心并放大，其余气泡靠碰撞力推开。
- **降级**：点击直接显示详情，不推挤。
- **别用在**：需要精确读数的场景；超过 30 个气泡。
