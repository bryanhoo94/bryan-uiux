# 动效质感（M1–M8）

参数预设、曲线、手势常量和通用规则见 SKILL.md，这里不重复。

这一组最重，也最容易做过头。只在组件和手势都做好之后加，而且多数只适合品牌页、首屏和低频场景。

### M1 磁吸

- **用在**：拖到目标区域（收藏夹、删除区、悬浮按钮吸边）；桌面端的磁吸按钮。
- **提示词**：做一个磁吸效果，元素靠近目标时先产生阻力，接近后快速贴合，吸力随距离减小而增强，不是匀速运动
- **参数**：吸附半径 R = 80px（起始值）。R 外 1:1 跟手；进入 R 后显示位置 = 手指位置 + (目标 − 手指) × `(1 − 距离 / R)²`，刚进范围时几乎不动（像阻力），越近越快。距离 < R × 0.25 时用 `spring-gesture` 贴合。要拖出 R × 1.3 才脱离（滞回，防抖动）。桌面磁吸按钮：鼠标在按钮范围内时，按钮朝鼠标方向偏移 30% 的距离，离开用 `spring-ui` 回位。
- **打断**：贴合后继续拖，超过脱离距离就用 `spring-ui` 回到手指下。
- **降级**：进入范围直接吸附，不做渐进吸力。
- **别用在**：需要精确对齐的编辑器，用 P5 参考线吸附。

### M2 液态形变

- **用在**：可拖动的卡片、气泡、悬浮按钮，想要有弹性、有生命力的品牌感页面。
- **提示词**：做一个液态形变效果，拖动卡片时形变与运动速度相关，拖得越快形变越明显，松手后慢慢恢复为原始形状
- **参数**：沿运动方向拉长、垂直方向压扁，面积不变：`sx = min(1 + 0.15 × |v|, 1.2)`、`sy = 1 / sx`（v 单位 px/ms，系数和上限都是起始值）。先旋转到速度方向，再缩放，再转回：`rotate(θ) scale(sx, sy) rotate(−θ)`。速度取最近几帧的平均值，否则会抖。松手后用 `spring-gesture` 回到原形，它的轻微回弹就是果冻感。
- **打断**：再次拖动时从当前形变继续算。
- **降级**：不形变，只平移。
- **别用在**：拖动中还要阅读文字的卡片（上限降到 1.05）；产品内高频拖拽，例如排序列表。

### M3 3D 视差

- **用在**：落地页首屏、卡片悬停、App 首屏插画。
- **提示词**：做一个3D视差效果，手指移动时不同层级的元素以不同速度位移，前景移动多、背景移动少，营造空间感
- **参数**：手指或鼠标相对容器中心的偏移，归一化到 −1 到 1，乘以每层的最大位移：前景 20px、中景 10px、背景 4px（起始值）。可以整体加 `rotateX / rotateY` 最多 8°，`perspective: 1000px`。用 spring 跟随（`spring-ui`），不要直接赋值，否则会抖；指针离开时 `spring-ui` 回到 0。
- **降级**：reduced-motion 时完全关闭。视差是最容易让人头晕的动效。
- **别用在**：产品内的数据页面（装饰性的指针跟随只属于营销页）；触屏没有 hover，不要为了它去申请陀螺仪权限。

### M4 中心聚焦放大

- **用在**：纵向卡片流、故事 / 内容 feed、滚动选择器。
- **提示词**：做一个中心聚焦放大效果，上下滚动时靠近屏幕中心的内容逐渐放大，离开中心后慢慢缩小，注意力自然被带到当前内容
- **参数**：由滚动驱动（同 P2）。Web 用 `animation-timeline: view()`，关键帧 0% `scale(0.9)` `opacity: 0.6` → 50% `scale(1)` `opacity: 1` → 100% 回到 0.9 / 0.6（起始值）。用缩小两边代替放大中间，这样不会溢出容器。配合 `scroll-snap-align: center`，停下时正好停在一项上。
- **降级**：去掉缩放，只保留透明度变化。
- **别用在**：需要同时比较多项的列表；文字密集的长文。

### M5 流动 Tab 切换

- **用在**：底部 Tab 栏、分段控件。
- **提示词**：做一个底部 Tab 切换效果，选中状态背景不是平移，而是先向前拉伸、再收缩、最后轻微回弹，像液体一样流到下一个tab
- **参数**：指示器的左右两条边分开动画。前沿先出发，用 `spring-gesture`；后沿用同一个 spring，延迟 60ms 出发（起始值）。中途指示器被拉长，后沿追上时收缩，前沿的 spring 自带轻微回弹。用 `translateX + scaleX`（`transform-origin: left`）实现，不要动 `left / width`。想更像液体，可以加 SVG gooey 滤镜。
- **打断**：快速连点时，两条边各自从当前位置转向新目标。
- **降级**：普通平移，200ms `--ease-out`。
- **别用在**：超过 5 个 Tab；两个 Tab 距离很远的桌面顶部导航（拉伸会很夸张，要限制最大拉伸长度）。

### M6 图片展开至全屏

- **用在**：相册、商品图、文章配图点开看大图。
- **提示词**：做一个图片展开至全屏的效果，页面中的小图片被拖动后向四周均匀扩张，始终保持视觉连续性，从局部到全屏转场自然连贯
- **参数**：共享元素转场。Web 用 View Transitions API（给小图和大图同一个 `view-transition-name`），或手写 FLIP：记下小图位置，从那里用 transform 扩到全屏。小图和大图比例不同时，用 `clip-path: inset()` 过渡裁切范围，不要拉伸图片。展开进度可以跟手（拖动或捏合向外，做法同 M7），过临界点就完成；点击展开用 `spring-ui`。背景遮罩透明度同步变化。关闭时往下拖缩回原位（按甩动常量判断）；原位置已滚出屏幕就缩小淡出。
- **打断**：展开中按住，从当前进度继续跟手。
- **降级**：直接交叉淡入全屏。
- **别用在**：图片本身很小、放大后糊掉的场景。

### M7 手势转场

- **用在**：页面切换、底部弹层、卡片展开成详情页，任何两个状态之间能用手拉的转场。
- **提示词**：做一个手势转场，页面切换由用户手势控制而非自动播放，拖一点走一点，拖到一半松手可回退，超过临界位置才完成转场
- **参数**：转场进度 = 拖动距离 / 转场总距离，1:1 跟手。Web 可以先把转场写成一段 WAAPI 动画，再把 `animation.currentTime` 设成「进度 × 时长」来拖动它。起手先做 G4 方向锁定。松手：速度 > 0.11 px/ms 就按速度方向决定；速度小才看进度是否过半。落位用 `spring-ui`，并传入松手速度。
- **打断**：遵守 G5，动画中随时可以按住。
- **降级**：手势保留，转场改成交叉淡入。
- **别用在**：没有例外，自动播放的转场都可以考虑改成这种。G1 边缘滑回是它的特例。

### M8 物理碰撞

- **用在**：标签云、兴趣选择、D10 气泡图、游戏化或庆祝场景。
- **提示词**：做一个物理碰撞效果，多个元素同时运动时加入碰撞推挤和回弹，不同大小的元素拥有不同的运动重量，遵循同一套物理规则
- **参数**：用物理引擎，不要手写。需要重力和回弹用 matter.js；只要推挤、不要重力用 d3-force。质量和面积成正比：大元素推小元素容易，反过来难。弹性（restitution）0.3、摩擦 0.1（起始值）。所有元素静止后暂停模拟，省电。引擎只负责算位置，DOM 用 `transform` 同步。
- **降级**：静态布局，不模拟。
- **别用在**：用户要阅读或操作的数据列表；超过 50 个元素；低端设备。
- **无障碍**：DOM 顺序保持逻辑顺序，不随物理位置变化。
